Firebase setup needed

Create a Firebase project, enable Email/Password auth, Firestore, and Storage. Paste your web config into loginViews/scripts/loginFirebaseConfig.js, then deploy rules: 

firebase deploy -c firebase.network.json --project YOUR_PROJECT_ID

QR code URL for check-in: https://keplersiguineau.com/login.html?checkin=1

First admin: after you register, set networkMembers/{your-uid}.admin = true in Firestore.
